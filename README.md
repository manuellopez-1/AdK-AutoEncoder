# AdK-AutoEncoder

**An autoencoder inspired by graph-based representations, developed to identify adenylate kinase (AdK) opening pathways using forward flux sampling (FFS) data.**

## Overview

This project demonstrates the use of deep learning to analyze the large datasets generated by [AdSamp]([https://github.com/](https://github.com/manuellopez-1/Advanced-Samp-Software)) through forward flux sampling. Specifically, an autoencoder is employed to identify structural similarities, distinguish intermediate states, and visualize the conformational pathways associated with AdK opening.

## Methodology

Each structure is represented using the pairwise distances between all alpha-carbon (Cα) atoms. These distances are transformed into values between 0 and 1 using:

\[
K_{ij} =
\begin{cases}
e^{-d_{ij}/0.8}, & i \neq j \\
0, & i = j
\end{cases}
\]

where \(d_{ij}\) is the distance between alpha carbons \(i\) and \(j\).

The resulting symmetric matrices are compressed using their upper-triangular elements and fed into a simple autoencoder composed primarily of dense layers. The network learns a two-dimensional latent representation of the molecular configurations, allowing the high-dimensional structural data to be visualized and analyzed.

Training minimizes a combination of reconstruction error, a distance-preservation loss in latent space, and a small latent-space regularization term.

## Results

The resulting latent space demonstrates strong separation between FFS steps, while also revealing distinct structural clusters within individual steps. Furthermore, the organization of structures in latent space provides insight into the relationships between configurations and the conformational changes associated with AdK opening.

Although structures from all FFS steps are provided independently, the learned latent representation captures similarities both within and between steps, making it possible to investigate structural pathways without explicitly providing trajectory connectivity to the network.
